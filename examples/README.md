# Examples

- `fixtures/pavilion-task.json`: original CC0 five-stage integration task, two distinct floors and predefined benchmark decisions. These decisions are test input, not real client approval.
- `fixtures/table.json` and texture script: editable Blender table fixture and exchange test. Blender source scripts are GPL; generated original geometry is CC0.
- `plan-e/`: owner-authorized Unified + Split refined building case, retained uncertainties, source catalogue and selected feedback lessons. Full SKP and actual native geometry are Release downloads, not Git blobs.

See [Release v0.1.0](https://github.com/Lsc1123/architectural-modeling-workflow/releases/tag/v0.1.0). Extract each example ZIP into a new workspace, retain its directory structure, then follow its manifest. Runtime operation logs are local diagnostics; only curated portable results are published. Never run acceptance scripts against a production workspace.

Plan E models are independent unchanged copies of the project's R10 refined architectural models. Historical evidence remains historical and scoped. This release adds native read/export and drawing-reader evidence, without making another Plan E design revision. See [verification](../validation/README.md) and [history lessons](../docs/history-lessons.json).
