# 建筑建模工作流与 MCP v0.1.0

首版包含五阶段技能、41 个实际 MCP 工具、SketchUp RBZ、独立 Blender 资产适配、几何核查及出图交接接口。

已在 macOS 27.2、SketchUp 26.0.428、Blender 4.5.12、Python 3.12 和官方 MCP SDK 2.3.0 验收。27 项核心/协议测试通过；最终代码三轮完整任务从候选到冻结交接通过，另有接续手改、资产往返、GUI 撤销及故障恢复记录。实际 Codex app-server 已发现并调用工具。

下载：

- `amw-sketchup-0.1.0.rbz`：SketchUp 扩展。
- Python wheel / source archive：MCP 服务及适配源代码。
- `architectural-modeling-workflow-skill-0.1.0.zip`：可安装技能。
- `plan-e-unified-split-0.1.0.zip`：完整精修 SKP、实际几何/材料/场景/语义索引、平剖底稿与验证边界；原模型无设计修改。
- `pavilion-three-rounds-0.1.0.zip`：三轮固定任务卡、阶段成果、原生显示核查及冻结交接包。选案/交接决定为预设测试输入，不是真实客户审批。
- `editable-table-roundtrip-0.1.0.zip`：可编辑 Blend、GLB/DAE/纹理与 SU 往返样件。
- `SHA256SUMS.json`：下载校验。
