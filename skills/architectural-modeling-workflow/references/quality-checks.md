# 分层验收与变更影响

只执行与当前阶段和变化相关的检查；主模型、证据和输出版本一致是前提。阶段交接扩大检查范围，不把每个小修改变成全量工程审查。

## 四种结论分开报告

| 类别 | 要回答的问题 | 可用证据 | 不能替代什么 |
|---|---|---|---|
| 设计与使用 | 是否符合本轮意图，空间是否好用 | 用户决策、白模/剖面、动作净空、原生查看 | 不由脚本“无错误”自动证明 |
| 原生与几何 | 是否能编辑，形体/连接是否正确 | 实体检查、编辑测试、轮廓、路径及碰撞报告 | 不等于承载、机电或规范合格 |
| 文件与显示 | 保存/导出是否完整且来自同版 | 指纹、保存重读、数量/坐标/材质对照、场景近景 | 不等于图纸专业表达或渲染质量 |
| 专项深化 | 尚欠哪些专业判断 | 明确未决项、适用依据、后续责任 | 不把未建系统写成已通过 |

## 按改动触发检查

| 改动 | 必查范围 | 常被遗漏的后果 |
|---|---|---|
| 区域编号/功能/连接 | 当前底表、用户最新决定、模型定位、连接两端及属性 | P号相似而认错房间；旧主链混入新方案；同层误算楼梯 |
| 墙/板/标高/洞口 | 相邻梯段、上下平台、门、结构支承、栏杆、完成面、面积口径 | 净高变化；首末级不一致；图纸尺寸过期 |
| 梯段或平台 | 每级标高与方向、起终点、通行带、上方障碍、栏杆转角、门扇 | 级数与踏面数混淆；上端平台重复；框架挤占净宽 |
| 钢梁/柱/连接板 | 玻璃、门窗框、楼梯、护栏、铺装、家具、灯帘 | 只查结构内部导致跨系统穿模 |
| 卫浴/固定家具 | 操作动作、门开启、通行、视线/隐私、围护、铺装、相邻设备 | 用实心柜堵住水槽；衣柜挡住错层；玻璃后缺隐私 |
| 铺装/饰面厚度 | 完成面标高、全部踏步含首末级、门槛、结构和底槽 | 整体抬高地坪；误把剩余厚度当作已核定结构厚度 |
| 灯具/窗帘 | 宿主墙/顶、安装关系、梁和柜、门窗开启、日夜状态 | 不碰撞但悬空；装在过高位置；两态同时出现 |
| 场景/可见性 | 对象自身、祖先群组、标签及场景的有效状态，是否保存相机 | 隐藏不等于删除；场景切换沿用旧视角；替代表达重复显示 |
| 导出/更新派生 | 单位、轴向、基准点、源指纹、ID、变换、材料、已有人工修改 | 应用父变换两次；旧网格重复；覆盖新材质/精绘 |

## 执行边界

通用要求统一见 [硬规则 R01–R10](hard-rules.md)。本页维护检查方法与触发范围，不重复规则正文。

- 包围盒用于候选初筛；实体相交检查需实际几何。薄片、非流形、布尔失败等未覆盖类型单列。
- 楼板比较完成面、底面和真实轮廓/孔洞；梯段比较下平台→第一踏面→中间级→末踏面→上平台。净空从完成面量。
- 门洞核对四角、全墙厚前中后切片、门槛与框墙收口。开口记录宿主、用途、边界及存废；封墙显示与废止洞口同查。
- 门梯路线记录身体宽高、门扇状态、转向和脚下支承面。障碍候选来自实际空间查询；离散状态不证明连续运动。
- 防护沿临空边检查，支承沿落点检查。碰撞修复后复查功能；有意连接逐对记录。
- 范围外比较覆盖稳定身份、世界几何、逐面材质/UV；场景和可见性变化另列。缺少可靠身份映射时不宣称全部未变。
- 披露容差、候选过滤、贴面偏移、内缩及采样密度。保留旧失败条件与改变检查范围的设计依据。
- 当前报告没有已认证的空间影响边界；空间检查继承保守比较全部导出环境，任何变化要求重查。局部拓扑仅比较原依赖，不扩展原检查范围。

## 视觉检查不能省略

至少查看能暴露本轮问题的原生整体视图和局部视图。选择低视点/剖面检查净空和墙板厚度，转角近景检查接缝、防护和悬空构件。用户已选择在原生软件查看时，内部留证即可，不强制输出图片包。

家具先看坐/起/拉椅/开柜/进门的动作带，再看大小、方向和成套关系。保留空地也是设计结果，不能以家具数量、实体数量或细节密度作为完成标准。

## 证据最小字段

每份正式核查报告记录：源模型SHA、时间、工具/脚本版本、检查对象与状态、方法与容差、结果、排除项、未覆盖范围、问题处置及关联截图/数据。旧报告无指纹时只作历史参考，除非另有可核对的同版证据。

写“本轮对象及邻接范围检查通过，未覆盖某项”，不要写“确认没有任何错误”。无法执行的检查写“未执行”，不用“应该通过”。
