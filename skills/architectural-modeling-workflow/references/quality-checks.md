# 分层验收与变更影响

只执行与当前阶段和变化相关的检查；主模型、证据和输出版本一致是前提。阶段交接扩大检查范围，不把每个小修改变成全量工程审查。

## 四种结论分开报告

| 类别 | 要回答的问题 | 可用证据 | 不能替代什么 |
|---|---|---|---|
| 设计与使用 | 是否符合本轮意图，空间是否好用 | 用户决策、白模/剖面、动作净空、原生查看 | 不由脚本“无错误”自动证明 |
| 原生与几何 | 是否能编辑，形体/连接是否正确 | 实体检查、编辑测试、轮廓、路径及碰撞报告 | 不等于承载、机电或规范合格 |
| 文件与显示 | 保存/导出是否完整且来自同版 | 指纹、保存重读、数量/坐标/材质对照、场景近景 | 不等于图纸专业表达或渲染质量 |
| 专项深化 | 尚欠哪些专业判断 | 明确未决项、适用依据、后续责任 | 不把未建系统写成已通过 |

## 按改动触发检查

| 改动 | 必查范围 | 常被遗漏的后果 |
|---|---|---|
| 区域编号/功能/连接 | 当前底表、用户最新决定、模型定位、连接两端及属性 | P号相似而认错房间；旧主链混入新方案；同层误算楼梯 |
| 墙/板/标高/洞口 | 相邻梯段、上下平台、门、结构支承、栏杆、完成面、面积口径 | 净高变化；首末级不一致；图纸尺寸过期 |
| 梯段或平台 | 每级标高与方向、起终点、通行带、上方障碍、栏杆转角、门扇 | 级数与踏面数混淆；上端平台重复；框架挤占净宽 |
| 钢梁/柱/连接板 | 玻璃、门窗框、楼梯、护栏、铺装、家具、灯帘 | 只查结构内部导致跨系统穿模 |
| 卫浴/固定家具 | 操作动作、门开启、通行、视线/隐私、围护、铺装、相邻设备 | 用实心柜堵住水槽；衣柜挡住错层；玻璃后缺隐私 |
| 铺装/饰面厚度 | 完成面标高、全部踏步含首末级、门槛、结构和底槽 | 整体抬高地坪；误把剩余厚度当作已核定结构厚度 |
| 灯具/窗帘 | 宿主墙/顶、安装关系、梁和柜、门窗开启、日夜状态 | 不碰撞但悬空；装在过高位置；两态同时出现 |
| 场景/可见性 | 对象自身、祖先群组、标签及场景的有效状态，是否保存相机 | 隐藏不等于删除；场景切换沿用旧视角；替代表达重复显示 |
| 导出/更新派生 | 单位、轴向、基准点、源指纹、ID、变换、材料、已有人工修改 | 应用父变换两次；旧网格重复；覆盖新材质/精绘 |

## 几何检查的执行规则

1. 包围盒用于候选筛选；实际碰撞用适合几何类型的相交方法。记录容差的物理单位和覆盖范围。
2. 相交结果逐类处理：意外碰撞要修；有意嵌入需记录双方ID、连接意图和保留理由；互斥状态不作为同时存在的实物检查。
3. 排除项不能只写“结构全部排除”。不同系统需要各自适用的检查：地下连通、支承关系、家具通道和安装宿主等。已排除内容若本轮改变，应重新评估。
4. 同根组内部装配、薄片、非流形或布尔失败对象若未覆盖，明确列为未检/需目检，不能落入“零碰撞”结论。
5. 踏步检查包括下平台→第一踏面、所有中间级、末踏面→上平台。净空从实际完成面量，不从旧结构板坐标推断。
6. 范围外比对至少覆盖稳定ID、世界几何和材质；有场景修改时加入可见性。ID重建需记录旧新映射；没有可靠映射时不能宣称全部未变。
7. 沿临空边检查防护连续性，沿支承链检查构件落点，沿水流方向检查排水连接。它们是关系检查，单个实体封闭不能代替。
8. 消除相交后，检查原构件的功能是否仍成立：围墙是否出现缺口、扶手是否中断、家具是否失去落地支承。能内退或重做收口时，不以删除必要围护作为通过依据。
9. 动作区或采样范围发生变化时，保留原失败结果及新范围依据，并检查实际使用动作。不能只改阈值、排除对象或缩小包络来消除报告中的失败项。
10. 楼梯净空、梯体安装槽与平台楼板分别建模。普通到达面不得用薄平台覆盖深槽来替代连续楼板；检查平台底与下部板的空隙、结构层与面层覆盖，以及到达面的重复实体。拆除或移动梯段后逐项关闭废弃开口，保留现用梯口的真实边界。范围外“楼板未改”不构成楼板正确的证据。
11. 门洞不得继承无明确所属构件的通行布尔切削。每个开口记录功能、宿主、边界、完成面、墙厚和存废状态；四角连续、洞内畅通、墙厚前中后切片均需核查。门框需随补墙收口；废止门洞连同封墙一起核查和显示。规则的楼梯穿墙口、门窗组合口按其真实轮廓核对，不一律改成矩形。缺陷回归须能先检出修复前问题，再对保存重读的几何通过；新设计不得通过单纯放宽基准消除失败。
12. 门与梯、平台相邻时，以完整动作链验收：门内接近/转身→开启/穿门→门外落脚→转向→平台或首末踏步。水平连接同时检查人体通行体与脚下实面覆盖；体积不相交不能发现地板缺失。障碍候选从实际模型空间查询，不能只选墙、门或某个专业图层。记录门扇使用状态；固定开启位置通过，不代表开启全过程通过。
13. 将几何缺陷保留为回归反例。同一合理动作、尺寸和碰撞对象集合，必须先检出旧问题，再检查保存重读后的修复；设计改变路线时明确旧、新路线和理由。检查区域、候选过滤包围盒、采样密度、贴面偏移、净宽内缩均属于检查边界，要随报告披露。
14. 每条连接按版本记录覆盖状态：已做实际几何检查、仅语义连通、待核查或不适用。图论连通、门洞检查、楼板检查、已绑定的旧报告分别回答不同问题，不能汇总为全屋可通行。无门的版本不得继承另一版本的穿门结论。

## 视觉检查不能省略

至少查看能暴露本轮问题的原生整体视图和局部视图。选择低视点/剖面检查净空和墙板厚度，转角近景检查接缝、防护和悬空构件。用户已选择在原生软件查看时，内部留证即可，不强制输出图片包。

家具先看坐/起/拉椅/开柜/进门的动作带，再看大小、方向和成套关系。保留空地也是设计结果，不能以家具数量、实体数量或细节密度作为完成标准。

## 证据最小字段

每份正式核查报告记录：源模型SHA、时间、工具/脚本版本、检查对象与状态、方法与容差、结果、排除项、未覆盖范围、问题处置及关联截图/数据。旧报告无指纹时只作历史参考，除非另有可核对的同版证据。

写“本轮对象及邻接范围检查通过，未覆盖某项”，不要写“确认没有任何错误”。无法执行的检查写“未执行”，不用“应该通过”。
