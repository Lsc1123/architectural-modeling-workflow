# 连续精修：把反馈转成可核查的局部修改

适用于用户保留总体方案，只调整家具、饰面、栏杆或局部接口的轮次。已有授权直接执行；以下是方法，不是新增审批步骤。项目编号、尺寸、相机和样例结果留在项目记录中。

## 先定位，再解释

将圈图与当前相机、可见构件和实体ID对应，记录“图中位置—区域功能—对象—用户动作”。屏幕上方不等于高楼层，旧组名不等于当前用途。误认区域时先纠正定位，再生成几何。追加反馈是对当前任务的修订：保留已认可的修改，明确它替代哪一条旧决定。

## 先检查使用动作，再调整姿态

修改卡另列“需要看见的空间关系”和“体量目标”。房间能容纳家具、路径能通过，只证明相应几何条件；还须从同一完整视角看占用体量，并从关键剖面或室内视角看高差与空间联系。增加房间隔断时区分户界、房间界、临空边和展示剖切，不用“独立使用”自动推导通高封墙。

紧凑湿区分别报告主体外包、内部净面、实际可用淋浴净宽和附属储藏；不把底盘标称尺寸当玻璃内净宽。折叠/滑动构件先确定收起、使用及中间动作状态，同时检查同组扇片互碰、邻近柜门、检修门与脚下实面，再细化连接件。

家具按进入、转身、落座、拉椅、经过和到达工作面的顺序布置。自然摆放通常指平面轻微转角，不默认倾斜家具使脚离地；从座面、靠背及目标桌面判断朝向，不仅看包围盒或组轴。

桌椅调整前列出依赖对象：灯体、灯线、顶座及实际安装面等。各对象按目标关系定位；同量平移会保留原有偏心，不能替代“桌灯重新居中”的测量。调整完成后查桌椅使用区、邻接柜门/冰箱及脚下实面。采样拉椅距离、人体宽高和门状态须写明；离散检查不冒充连续运动、开门全过程或无障碍验收。

## 风格变更同时查连接与功能

“与现有构件同款”先提取截面、材质、实体与空隙比例、支承间距和端部回落，再应用到实际同类对象。不可只复制颜色或删填充而不修转角。用户明确取消的表达不自行恢复；外观决定与防护、承载等性能结论分开登记，未深化的功能保留为未决项。

支承与收口按真实邻接实体检查。托杆可能接在相邻转角扶手上，不能只检查同组主杆；候选范围扩展必须有空间关系和实体证据。相交区分有意连接与碰撞，不能为“零相交”切断必要节点。

## 比较同一范围，分别验证不同版本

完整原生导出与筛选后的发布几何先统一根组、隐藏/退役规则和稳定ID范围，再比较数量、表面、材质及UV。数量不同不自动意味着丢构件；须解释差异中的每类对象。保存场景相机和隐藏状态另查，保留用户当前视角。

两版共享构件可比较，但路线不能机械复用。若一版保留独有楼梯，先复现冲突，再据真实通路改路线并记录理由；不要删障碍、缩人体或收窄候选集来获得通过。相机位置用物理距离容差，方向向量用无量纲误差，避免以浮点逐位相等判定视觉变化；容差根据尺度预先选定，异常须解释后再调整。

## 窗口保全与有界恢复

记录应用文档路径、观察时间、未保存状态和独立快照。快照只能保护保存当时的内容，不能证明之后没有手改；原生全量对比也不能推断窗口的modified标志为false。遇到保存/放弃提示，未查明时取消关闭。

界面操作首次异常先刷新状态，再尝试一次有依据的替代路径；仍失败则使用已验证的API、原生副本或文件检查完成独立工作，避免反复点同一菜单。锁屏时停止界面操作，说明原生打开或显示尚未完成；解锁后重新读状态，不能按旧控件编号继续操作。

## 按依赖完成并收口

定位与范围 → 关键样件 → 原生写入 → 原生编辑/撤销及必要场景整理 → 最后保存并重读 → 实际几何核查 → 必要视图目视复核 → 更新当前入口。只并行独立步骤。出图或场景操作再次保存模型时，重新读取受影响数据并绑定最终文件；不能只刷新报告哈希。小改动只重跑受影响的检查和图；复用证据要说明来源版本、保持依据和失效范围，新增邻接不能仅靠旧构件未变而跳过。

调整试算路线时，保留失败路径、碰撞位置和新路线理由；人体尺寸、障碍集与净高不随结果收缩。空间实际不足则改设计，不以路径挪动代替。核查图先确认镜头所在区域、完成面和剖切方向；同一XY在错层模型里可能属于不同楼层。未看到目标的截图不作为完成证据。沿用用户精简后的场景，不为临时诊断不断增加持久场景。

发布时核对事实底表、根入口、交接路径和旧说明的历史标识。路径和指纹从当前事实读取，历史测量注明版本，不当作本轮实测。普通精修保留必要证据即可；阶段交接才汇总长文档，避免每次小改都制造一套重复报告。
